#   https://{slug}.sso.weldforge.org/{login,forgot-password,reset-password,register,verify-email}

# goal of the per-tenant URLs. AI agents that need to know how end users
# sign in should read /llms.txt or /agents.html on this site, not crawl
# the auth forms themselves.
